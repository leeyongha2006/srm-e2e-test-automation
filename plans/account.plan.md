# 테스트 계획: Account (Salesforce 표준 화면)

근거: 표준 Account 오브젝트 · 기본 레이아웃. 셀렉터는 실제 화면을 조작해 확인한 접근성 이름(role, label)을 쓴다.

| # | 시나리오 | 기대 결과 | 불안정 요소와 대응 |
|---|---|---|---|
| 1 | 목록 화면 열기 | Account Name 열, 행 1개 이상 | 그리드가 행을 나눠 그림 → 행 수가 안정될 때까지 대기 |
| 2 | 새 거래처 저장 (Rating = Hot) | 상세 화면에 이름과 Rating 표시 | 토스트가 버튼을 가림 → 닫고 진행. 성공은 토스트가 아니라 저장된 값으로 확인 |
